# Yamaha TT600 59X Buying Workflow

Goal: make parts buying repeatable for a niche bike where many listings are under XT600, not TT600 59X.

## Core rule

Never buy from model-name similarity alone. Buy in this order:

1. Identify the function and the assembly on the bike.
2. Check whether the workspace already links that assembly to a donor family.
3. Search by OEM part number if you have it.
4. If there is no part number, search by model code plus assembly name.
5. For used parts, compare photos, mounting geometry, and connector style before paying.

## Decision tree by part type

### Consumables

Buy new.

Examples:

- Fork seals and dust seals
- Brake fluid, pads, hoses
- Oil, filters, drain washers
- Spark plug and plug cap
- Intake manifolds if cracked
- Carb seals and O-rings

### Hard parts with known interchange

Search both TT600 59X and XT600 donor families.

Examples:

- Front speedo drive
- Levers and cables
- Rear shock family replacements
- Ignition coil in a 12V-converted setup

### Rare electronics

Do not buy blind used electronics unless the seller can prove testing.

Examples:

- CDI
- Stator
- Regulator / rectifier

Preferred approach:

1. Buy a complete matched 3TB electrical donor set for a conversion.
2. Or buy a known aftermarket CDI after confirming 59X curve support.
3. Ask the seller for connector photos and resistance readings where possible.

### Large assemblies

Used can make sense, but only if shipping and damage risk are reasonable.

Examples:

- Tank
- Forks
- Swingarm
- Wheels
- Engine or top-end donor parts

## Seller checks before buying used parts

- Ask for the exact model code the part came from.
- Ask for close photos of mounting points, casting marks, connector plugs, and wear surfaces.
- Ask whether the part was tested on a running bike.
- Ask for measurements when fitment is uncertain.
- Reject vague listings that only say fits XT/TT without model code or part number.

## Priority shopping groups for your restoration

Based on the existing workbook and notes, this is the practical order:

1. Safety and baseline service
2. Intake sealing and carb refresh
3. Drive chain and control reliability
4. Suspension refresh
5. Electrical strategy decision: keep original 6V or convert to matched 3TB 12V
6. Cosmetics and bodywork
