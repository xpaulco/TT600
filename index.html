12V Architecture

The conversion is a system problem, not a shopping list problem.

The page below is the execution logic: mount layout first, minimum ignition test second, full loom third, full power-up last.

Open 12V basket
1

Lock the hardware positions

Decide battery position, fuse block position, and regulator airflow before loom construction. The 59X oil tank forces the battery packaging problem early.

2

Buy loom materials in one batch

Battery, fuse block, inline fuse, wire, connectors, loom tape, heat shrink, split conduit, and 12V bulbs should be treated as a single electrical-supplies order.

3

Secure a matched 3TB donor set

Stator, flywheel, CDI, and regulator/rectifier should ideally come from one XT600 3TB donor bike or one coherent seller bundle.

4

Test spark before finishing the loom

Minimum ignition circuit first. Full wrapping comes only after spark, charging voltage, earth continuity, and kill-switch behavior are confirmed.

CDI Decision

Used matched donor first. Aftermarket fallback second.

The choice is not really “which CDI is cheaper.” The real choice is “coherent donor system versus fragmented electrics.”

Open full comparison

Preferred path: used 3TB CDI inside a matched donor set

  • Best fit with the 3TB stator and flywheel strategy.
  • Usually lower cost if the seller can prove provenance.
  • Best when multiple parts come from the same running bike.

Fallback path: aftermarket 3TB CDI

  • Higher cost, but more predictable than random used CDI listings.
  • Still only sensible in a full 3TB conversion.
  • Useful when donor CDI provenance is weak but the rest of the set is good.

Working Rule

Compatibility first for electrics, speed second for service parts.

If a part changes charging, ignition, trigger pickup, or 12V architecture, stop and confirm donor-system coherence before buying. If the part is normal service hardware or intake rubber, buy it from the cleanest supplier basket and move on.

Best current move

1. Place the KEDO service order.

2. Buy loom materials as one electrical batch.

3. Hunt a matched XT600 3TB donor set using the lead tracker and seller templates.
