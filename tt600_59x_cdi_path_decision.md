# TT600 59X CDI Path Decision Sheet

Date: 2026-09-04

Decision to make: for a full 12V conversion, should the ignition path use a used XT600 3TB CDI from a matched donor set, or a new aftermarket CDI from RegulatorRectifier?

## The two viable paths

### Path A: used 3TB donor CDI

- Target reference: 3TB-82305-00 or 3TB-82305-10 family
- Best acquired as part of the complete 3TB donor electrical set
- Planning range in current budget: EUR 80-180 for CDI alone

### Path B: new aftermarket CDI

- Source: RegulatorRectifier live product page
- Reference it replaces: 3TB-82305-00-00 and 3TB-82305-10-00
- Current captured price: USD 299.99

## Core comparison

| Criterion | Path A: used 3TB donor CDI | Path B: aftermarket CDI |
|---|---|---|
| Purchase price | Lower | Higher |
| Availability predictability | Lower | Higher if the product stays live |
| Match with donor stator/flywheel | Best when bought as full donor set | Acceptable, but still only sensible in a full 3TB conversion |
| Electrical risk | Lower if the set is complete and proven | Moderate because it is aftermarket and may need mounting adaptation |
| Installation simplicity | Good if matching plugs are included | Good electrically per listing, but mounting may need custom work |
| Traceability | Depends on seller honesty | Better product identity, warranty-backed |
| Warranty | Usually none | Listing states 3-year exchange warranty |
| Failure-history unknowns | High on old used electronics | Lower than random used part, but still non-OEM behavior |
| Best use case | Best-value matched donor build | Fastest clean solution when donor CDI availability is poor |

## Cost logic inside your current plan

### Used-donor-oriented ignition path

If you buy the used donor pieces as separate items, current planning ranges are:

- stator: EUR 60-140
- flywheel: EUR 40-100
- CDI: EUR 80-180
- regulator/rectifier: EUR 40-120
- coil: EUR 20-60

That puts the electrical core roughly at:

- low end: EUR 240
- high end: EUR 600

The financial upside is that a complete donor lot can land below the sum of separate parts.

### Aftermarket-CDI-oriented path

If you buy the new CDI, you still need:

- stator
- flywheel
- regulator/rectifier
- coil

So the CDI decision does not eliminate donor hunting. It only removes one used-electronics variable.

Using the current planning ranges plus the fixed aftermarket CDI price:

- stator: EUR 60-140
- flywheel: EUR 40-100
- regulator/rectifier: EUR 40-120
- coil: EUR 20-60
- CDI: USD 299.99

This path is usually more expensive overall unless the used CDI market is terrible or unreliable.

## Risk logic

### Why the used donor CDI path is stronger in principle

- The wiring guide already assumes a matched 3TB system.
- A donor set preserves the original relationship between stator trigger, flywheel, CDI, and regulator.
- The biggest practical risk in these conversions is mismatched components, not the CDI alone.

### Why the aftermarket CDI path can still make sense

- If the used CDI market is full of untested parts.
- If complete donor sets are rare and you find a good stator/flywheel pair but no trustworthy CDI.
- If you value warranty and repeatability over raw parts cost.

## My recommendation

Primary recommendation:

1. Hunt for a complete 3TB donor electrical set first.
2. Use the used 3TB CDI path if the set is coherent, tested, and comes from one bike.

Fallback recommendation:

1. If you secure a good stator + flywheel + regulator set but cannot find a trustworthy CDI, switch to the aftermarket CDI.

## Decision rule

Choose Path A if all these are true:

- one seller can provide most or all of the 3TB electrical set
- donor model/year is clear
- connector photos and markings are clear
- seller can describe charging or running condition credibly

Choose Path B if any of these are true:

- used CDI provenance is weak
- donor listings are fragmented and contradictory
- you want to reduce one major failure variable and accept higher cost

## Bottom line

For this project, the best engineering choice is not “used CDI versus aftermarket CDI” in isolation. It is “matched donor system versus fragmented parts.”

That means:

- first choice: used 3TB CDI as part of a matched donor set
- second choice: aftermarket CDI when the donor CDI is the weak link in an otherwise good 3TB conversion plan
