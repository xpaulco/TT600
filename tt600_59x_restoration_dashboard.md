# TT600 59X Restoration Dashboard

Date: 2026-09-04

This is the master index for the project. Use it as the single entry point instead of jumping between files blindly.

## What this dashboard is for

- identify which file answers which question
- know what to buy now versus later
- keep the 12V conversion coherent
- avoid duplicate work and duplicate shipping

## Recommended workflow

1. Read [tt600_59x_best_buy_order.md](tt600_59x_best_buy_order.md).
2. Place the KEDO service order first.
3. Use [tt600_59x_vendor_grouped_purchase_list_2026-09-04.csv](tt600_59x_vendor_grouped_purchase_list_2026-09-04.csv) to keep orders grouped by supplier.
4. Hunt the matched XT600 3TB donor set using [tt600_59x_3tb_donor_leads.csv](tt600_59x_3tb_donor_leads.csv).
5. Build the conversion using [tt600_59x_12v_conversion_basket.md](tt600_59x_12v_conversion_basket.md) and [tt600_59x_wiring_loom_guide.html](tt600_59x_wiring_loom_guide.html).
6. Update [tt600_59x_budget_estimate_2026-09-04.csv](tt600_59x_budget_estimate_2026-09-04.csv) with real prices as donor parts are found.

## Current practical recommendation

- Buy the service and intake parts now.
- Delay the electrical install until the 3TB donor system is coherent.
- Treat the conversion as a matched system problem, not a single-part problem.

If it is a normal service or intake part, buy it now from the cleanest supplier basket.
